# 🧭 Terminal Quest

## Overview

**Terminal Quest** is a command-line based text adventure game developed in C++. It offers players an immersive experience through interactive storytelling and decision-making. Navigate through various scenarios, make choices, and explore the outcomes of your decisions.

## Features

- 🎮 **Interactive Gameplay** – Engage with the game through text-based commands and receive dynamic responses.
- 🧠 **Decision-Based Outcomes** – Your choices influence the direction and outcome of the story.
- 🧱 **Modular Design** – Easily extend or modify the game by adding new scenarios or choices.

## Getting Started

Follow these steps to run the game locally on your system:

### 1. Clone the Repository
```bash
git clone https://github.com/Kuldeep1462/Text-Adventure.git
````

### 2. Navigate to the Project Directory

```bash
cd Text-Adventure
```

### 3. Compile the Game

```bash
g++ text-adventure.cpp -o terminal_quest
```

### 4. Run the Game

```bash
./terminal_quest
```
